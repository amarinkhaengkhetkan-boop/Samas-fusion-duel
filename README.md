# SAMAS CODEBREAKERS: FUSION DUEL — เว็บแอป

เกมการ์ดดวลคำสมาส–คำสนธิ เล่นได้ 2 แบบ:
- **เครื่องเดียว** — ไม่ต้องล็อกอิน แตะเล่นบนจอเดียว (ใช้ได้ทันทีหลังเผยแพร่)
- **ออนไลน์** — ล็อกอิน Google → สร้างห้อง (รหัสห้อง 6 หลัก + รหัสผ่าน + QR) → ผู้เล่นเลือกทีม → **ทั้งสองทีมกด “พร้อม” เกมจึงเริ่ม** → การ์ดในมือของแต่ละทีมเห็นเฉพาะทีมตัวเอง

ระบบออนไลน์ใช้ **Firebase (ฟรี)** ส่วนตัวเว็บใช้ **GitHub Pages (ฟรี)** — ตั้งค่าครั้งเดียวตามขั้นตอนด้านล่าง (ประมาณ 15–20 นาที)

---

## ขั้นที่ 1 · สร้างโปรเจกต์ Firebase
1. เข้า https://console.firebase.google.com แล้วกด **Create a project / เพิ่มโปรเจกต์** ตั้งชื่อ เช่น `fusion-duel` (ปิด Google Analytics ได้)

## ขั้นที่ 2 · เปิดล็อกอินด้วย Google
1. เมนูซ้าย **Build → Authentication → Get started**
2. แท็บ **Sign-in method** → เลือก **Google** → เปิด **Enable** → เลือกอีเมลผู้ดูแล → **Save**

## ขั้นที่ 3 · อนุญาตโดเมนของเว็บ
1. **Authentication → Settings → Authorized domains → Add domain**
2. ใส่ `ชื่อผู้ใช้github.github.io` (เช่น `amarin-k.github.io`)

## ขั้นที่ 4 · สร้างฐานข้อมูลและใส่กฎความปลอดภัย
1. **Build → Realtime Database → Create Database** → เลือกที่ตั้ง **Singapore (asia-southeast1)** → **Start in locked mode**
2. แท็บ **Rules** → ลบของเดิม → คัดลอกทั้งหมดจากไฟล์ `database.rules.json` ไปวาง → **Publish**
   (กฎนี้ทำให้: เข้าห้องได้เฉพาะคนที่รู้รหัสผ่าน · ทีมหนึ่งอ่านการ์ดในมือของอีกทีมไม่ได้ · ส่งคำสั่งได้เฉพาะเจ้าของที่นั่ง)

## ขั้นที่ 5 · คัดลอกค่าตั้งค่าเว็บ
1. ⚙ **Project settings → General → Your apps →** กดไอคอน **`</>` (Web)** → ตั้งชื่อแอป → **Register app**
2. คัดลอกค่าใน `firebaseConfig` มาใส่ในไฟล์ **`js/firebase-config.js`** (ต้องมี `databaseURL` ด้วย — ถ้าไม่มี ให้คัดลอก URL จากหน้า Realtime Database)

## ขั้นที่ 6 · เผยแพร่บน GitHub Pages
1. ล็อกอิน https://github.com → **New repository** → ตั้งชื่อ เช่น `fusion-duel` → **Public** → **Create repository**
2. กด **uploading an existing file** → ลากไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์นี้ (index.html, css, js, assets, …) ไปวาง → **Commit changes**
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**
4. รอ 1–2 นาที เว็บจะอยู่ที่ `https://ชื่อผู้ใช้github.github.io/fusion-duel/`

## วิธีเล่นในห้องเรียน
1. ครูเปิดเว็บบนโน้ตบุ๊กที่ต่อทีวี → ล็อกอิน Google → **สร้างห้องใหม่** → เลือก “จอกลาง / ครู”
2. จอจะแสดง **รหัสห้อง + รหัสผ่าน + QR** → ตัวแทนแต่ละทีมสแกน QR ด้วยมือถือ → ล็อกอิน Google → ใส่รหัสผ่าน → กด **นั่งทีม A/B**
3. ทั้งสองทีมกด **พร้อม** → เกมเริ่ม: ทีวีแสดงสนาม · มือถือแสดงการ์ดในมือของทีมตัวเอง
4. คำถามเป็นแบบเลือกตอบ ทีมที่ถึงตาตอบบนมือถือ ระบบตรวจคำตอบเอง (ครูกดตัวเลือกแทนบนจอกลางได้)

**ดวลกันสองคนโดยไม่มีจอกลาง:** ตอนสร้างห้องเลือก “ผู้เล่นทีม A” แล้วให้เพื่อนเข้าห้องเป็นทีม B

## หมายเหตุ
- เครื่องที่สร้างห้องเป็นตัวรันเกม ต้องเปิดค้างไว้ตลอด ถ้ารีเฟรช ให้กด “ห้องล่าสุด — กลับเข้าห้อง” เกมจะเล่นต่อจากเดิม
- ในโหมดดวลสองคน เครื่องของผู้สร้างห้องเก็บข้อมูลเกมทั้งหมดไว้ในเบราว์เซอร์ (หน้าจอไม่แสดงการ์ดของคู่แข่ง แต่คนที่เปิดเครื่องมือนักพัฒนาอาจแอบดูได้) — ในห้องเรียนแนะนำให้ครูเป็นผู้สร้างห้องแบบจอกลาง
- Firebase แผนฟรี (Spark) รองรับการเชื่อมต่อพร้อมกัน 100 เครื่อง เพียงพอสำหรับหลายห้องเรียน
- ข้อมูลการ์ดอยู่ใน `js/game-data.js` (สำเนาอ่านง่ายที่ `game-data.json`) รูปการ์ดอยู่ใน `assets/`
